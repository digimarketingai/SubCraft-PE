**SubCraft-PE** is an interactive **AI Audiovisual Translation (AVT) & Machine Translation Post-Editing (MTPE) Workbench** designed for translation classrooms, subtitling workshops, and bilingual media production.

Built by **[digimarketingai](https://github.com/digimarketingai)**, it combines **anti-drift SOTA speech recognition**, **whole-passage context-aware neural translation**, **one-click classroom sample clips**, and **automated C-E / E-C post-editing strategy analytics** with Landscape A4 PDF report generation.
